# Visual development and references

Browse the [22-image HTML index](Visual_Index.html) or [PDF index](Visual_Index.pdf). [FILE_MANIFEST.json](FILE_MANIFEST.json) records each original's identity, role/approval status, dimensions, byte length and SHA-256.

| Folder | Role |
| --- | --- |
| `00_References/` | A01/A02: approved character identity and drawn style. A03: selected crisis-mood reference only, without its photographic treatment. |
| `01_Characters/` | Candidate character cutouts and angle sheets; flattened images, not fully rigged puppets. |
| `02_Expressions/` | Expression-sheet candidates, not aligned animation strips. |
| `03_Story/` | Candidate story plates. V2 deliberately excludes S05. |
| `04_Performance/` | Candidate performance and bridge-plea imagery. |
| `05_Backgrounds/` | Drawn setting candidates. |

Read the [v2 art handoff](../notes/Music_Video_Anime_Content_v2_Handoff.md) for identity, anatomy, wardrobe and acting constraints; the [current decisions](../DECISIONS.md) explain which later R4 directions govern the current cut. Presence in this selection does not prove Dario approved that image for a shot.

The active Short's runtime assets are in `../current/assets/`, including newer movie sources and mouth variants. This visual-development folder is not an automatically synchronized replacement for them. Preserve the original manifest and exact source files. Record any new candidate's origin and status separately, then promote only the inspected asset needed by the chosen shot. Older art IDs can repeat in restored v1 material, so use full paths when referring to an image.
