# Current edit: source and generated-file map

The hybrid Revision 4 is the current working reference. Read [the production status](../STATUS.md), [HANDOFF.txt](HANDOFF.txt), and [README.txt](README.txt) before a picture, sound or timing change. Keep this directory's script-relative paths and the adjacent `assets/` layout intact.

## Editable inputs

| Files | Role |
| --- | --- |
| `camera_shots_experimental.json` | Authoritative hybrid source/shot/camera schedule, including portrait `vert` camera values. |
| `camera_shots_simple.json` | Restrained Revision 3 comparison schedule. |
| `build_film.py` | Consumes the schedule and art, constructs animation/camera keys, validates coverage, and saves the selected scene. |
| `native_animation.py` | Drawn mouth exposures and tiny torso-interior controls used by the builder, including the held vowel through frame 339. |
| `finish.py` | Authoritative caption wording/timing (`CUES`), title styling, logo composite and encoding. |
| `audio.mp4` | Supplied AAC Short audio; retain its payload for full-length Short exports. Preview excerpts re-encode AAC. |
| `assets/` | Runtime art, mouth/blink variants, two original action movies and their endpoint stills, identity references and original wordmark. Origins/costs: `generation_manifest.json` and `brand_source.json`. |
| `Join_Me_in_Life_{experimental,simple}_{vert,wide}.blend` | Four portable tracked scenes. A direct scene edit is valid source work, but a script rebuild replaces it. Record which route a candidate uses. |

For a schedule/animation edit, rebuild the affected scene before rendering. For a direct scene edit, render the saved scene without rebuilding. [BLENDER.md](../BLENDER.md) gives both procedures. Clearing affected cached frames is necessary because the renderer skips existing JPEGs.

## Generated derivatives currently retained in Git

| Files | Producer / treatment |
| --- | --- |
| `shot_list_*.json` | Builder snapshots of the corresponding camera schedule. Edit the schedule, not these copies. |
| `validation_{experimental,simple}_{vert,wide}.json` | Per-frame scene coverage reports from `build_film.py`; preserve original evidence when making a candidate. |
| `Join_Me_in_Life_English.srt`, `lyrics*.ass`, `titles*.ass`, `lyric_cues.json` | Generated by `finish.py`. Change `CUES` or styling code, then regenerate and inspect the derivatives. They are not independent caption authorities. |
| `word_timing.json` | Alignment evidence used by the original animation/finishing work. It does not override corrected cue wording or the held-vowel exposure. |

`finish.py` writes these caption derivatives even for preview encoding. `build_film.py` saves the scene and reports even without `--render`. Use a task branch/worktree and inspect `git diff` after either command; neither is a read-only check.

## Baseline evidence and retained history

- `HANDOFF.txt`, `README.txt`, `REVIEW_NOTES.txt`: original archived delivery instructions and review history. Current session state is maintained one level above in STATUS/DECISIONS/SESSIONS.
- `camera_revision_report.json`, `waiting_room_seam_checks.json`, `focused_change_validation.json`: Revision 4 continuity, held-vowel and changed-frame evidence.
- `delivery_validation.json`: original hashes, frame counts, audio-payload checks and delivery properties. `tools/review.py` uses these to verify the original baseline.
- `portability_validation.json`: relative movie paths and packed media checks.
- `exports/Join_Me_in_Life_Short_Hybrid_Camera.mp4`: tracked captioned portrait baseline. Optional original alternates restore into `exports/`; new encoder output goes to `../Revision_4/`.

Do not replace original baseline hashes with a new candidate's hashes to make a baseline check pass. Save candidate validation/review separately under `build/` or a durable revision-specific record, and link it from the session log.

## Utilities and outputs

| Utility | Reads / writes |
| --- | --- |
| `render_existing.py` | Opens the selected saved scene, renders inclusive frame ranges under `frames/<cut>/<format>/`, skips existing files; does not resave the scene. |
| `review_camera.py` | Renders reduced-resolution camera endpoints under `camera_review/`. |
| `review_revision4.py` | Renders targeted R4 vowel/join samples under `revision4_review/`. |
| `make_portable.py` | Resaves all four scenes with relative paths and writes `portability_validation.json`. Maintenance operation, not a read-only runtime probe. |
| `validate_delivery.py` | Expects all six full exports under `../Revision_4/`; rewrites `delivery_validation.json`. Preserve original baseline evidence and use an isolated candidate copy if invoking it. It is not the preview validator. |
| `package_project.py` | Expects six full `_Camera.mp4` exports in `../Revision_4/`; writes the portable ZIP there. It is not a package command for one preview. |

Frame caches, camera reviews, previews, delivery folders and ZIPs are ignored. Media recovery restores original optional files; it does not turn a candidate into an accepted cut.
