# Technical references

`blender-pilot/` contains the earlier **eight-second, silent, 1280 × 720, 24 fps** Blender study: editable scene, build script, five PNG assets, MP4 and [original README](blender-pilot/README.txt).

It demonstrates limited deformation, blinks, a pose cut and camera motion. It is neither the current narrative Short nor a full facial/body rig. The original build script defaults to 1080p, while the recovered delivered scene/video are 720p. Inspect the actual scene before stating output properties.

Use a copy for experiments: rebuilding this pilot writes beside its source and can replace reference files. Its historical runtime paths are not current setup instructions. [BLENDER.md](../BLENDER.md) documents the active production runtime; [the current edit](../current/SOURCES.md) has its own scene, audio, camera schedule and rendering path.
