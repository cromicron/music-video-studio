## Matching endpoint guides do not control quiet acting

The four-take quiet run completed technically, including 201 frames within dual-T4 memory. Independent reviews nevertheless rejected the full-width window for mismatched reflected eyelids, pre-contact waiting for a hand-to-mouth/outward gesture, and the later held aftermath for grip release/point/regrip. Preserve these exact failures, not just the success status. The [window fixed crop](full-film/review/ltx23-window-closeup-review.md) salvages coherent acting by excluding the faulty reflected eyes; it does not repair or approve the original wide reflection. A06 and only the first L05 portion have scoped source passes.

[Correction research](full-film/research/quiet-motion-correction.md) supports a bounded positive-prompt comparison using the unchanged seed, images, duration and distilled settings. Forbidden-action words causing the failures is a hypothesis, not established causation. The pinned runtime encodes one positive context at current NAG; negative-field edits alone have no effect, and NAG changes would violate the validated one-use Gemma residency path. Intermediate guides exist upstream but need separate auditing and resource validation. Do not run the queued hospital batches unchanged just because the long-frame memory test succeeded.
