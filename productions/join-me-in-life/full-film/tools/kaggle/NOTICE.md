The direct runner adapts the NF4/FP16 dual-T4 placement and chunked feed-forward method from [DamnKuldeep/ltxv-13b-distilled-free-gpu-pipeline](https://github.com/DamnKuldeep/ltxv-13b-distilled-free-gpu-pipeline), commit `38f99fa7a1d52191d60a82ea07467e0de170a1f9`, licensed under Apache-2.0. Its license is retained as `LICENSE.creator.txt` beside this file. The owned modifications are a private batch CLI, official file allowlist/hash lock, bounded pilot, staged text encoding/unloading, exact frame validation, provenance and resumability. No creator Gradio server, public tunnel, NIM prompt service, LoRA, third-party weight cache, silent OOM shortening, or automatic extension is used.

The weights are the official **Lightricks/LTX-Video-0.9.8-13B-distilled**, revision `7c64400e1861cc0d7b98d570a1926d5408ec60cd`. `model-lock.json` records official byte counts and SHA256 hashes. The model has the separate [LTX-Video Open Weights License 0.X](https://huggingface.co/Lightricks/LTX-Video/blob/main/LTX-Video-Open-Weights-License-0.X.txt), including use restrictions and the $10m commercial revenue threshold. The code license does not replace the model license or license the user's artwork. Retain required machine-generated disclosure in publication credits/description.

Diffusers **0.37.0** supplies the deterministic scheduler and decode behavior. Its [LTX condition pipeline](https://github.com/huggingface/diffusers/blob/v0.37.0/src/diffusers/pipelines/ltx/pipeline_ltx_condition.py) supports image conditions at explicit frame indices. Our manual GPU1 decode includes its latent denormalization **and decode-noise interpolation**; the creator's manual decode omitted the latter. Its optional tone-map argument is absent in this pinned pipeline and is not claimed or silently simulated here. The stochastic scheduler correction used in the older CPU experiment is not applied: the official 13B scheduler has `stochastic_sampling=false`.

The pinned direct dependencies were selected against their published version constraints; their GPU integration remains to be tested on the actual Kaggle runtime. No third-party model code is downloaded/executed, and no Hugging Face token is read or required for these currently ungated weights.
