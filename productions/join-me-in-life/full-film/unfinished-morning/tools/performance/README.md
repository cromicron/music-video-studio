# C original-song performance batches

This separate adapter stages selected **C-prefixed** takes and `darionalis/jml-c-*` destinations. It refuses old queues. It derives from the retained revision2 adapter, preserving the neural `runtime.py`, backend/model/dependency locks, source patches, text/video residency, preflight and bounded child execution. Only selection/validation, codec frame whitelist and isolated output names change.

The current root authorization is a new two-take **97-frame first plea + 129-frame second plea** pilot, once exact C start images pass independent review. No old private performance notebook is resumed. Each take uses one seed49 attempt, 896×512,24fps, first image only, six leading frames and at least seven trailing frames. Original48k stereo PCM16 is cut from unchanged take49 at `(timeline_start - 6) × 2000` samples; no padding, retiming or generated model audio enters delivery.

Actual A2V hardware proof previously reached105frames. The129-frame encoder/memory case is unproven and must return actual evidence. The real pinned latent-shape code requires101/118/134 audio latent frames for97/113/129 pictureframes. Offline tests execute the actual shape and short-coverage rejection branch, but do not establish real encoder or GPU success. The guard must not be weakened.

[prepare_bundle.py](prepare_bundle.py) accepts `--plan` and `--output`; use schema `jml-c-performance-plan/v1`, state `ready_for_local_staging`, one to five unique C-prefixed take IDs and queue ID. Source paths are repository-relative and hash-bound. Independent source review keeps the existing `pairs` and `inspection.native_review_crops` contract: exact C shot ID, passed static suitability, exact viewed PNG hash and panel label. The copied original schema strings in returned manifests are transport compatibility, not a claim that the old story is current.

Fresh serial children share installed dependencies and disk weights. Provider cap5400s, inner cap5390s, no automatic retries. Outputs use `jml-c-performance-results`; the original-song review MKV uses exact stereo PCM. [verify_download.py](verify_download.py) checks real downloaded sources, actual fitted pixels, model/audio conditioning records, complete frame decode and original review PCM. It grants no creative acceptance.
