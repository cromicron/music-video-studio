# Keyboardist — first character proposal

Created from Dario's supplied selfie on 8 November 2026 using ChatGPT image generation, with the existing [chorus performance image](../../../productions/join-me-in-life/art/04_Performance/P02_Chorus_Performance.png) as the drawing/stage reference. The selfie was supplied in chat; a portable copy has not been retained here. [Exact generation prompt](prompt-v1.txt).

Dario called the completed C film promising and requested an all-male full band with drums, keys and other instruments, eventually intercut with the narrative. His immediate instruction is to develop his own fictionalized keyboardist first, alone with the keyboard, changing his hairstyle and reducing exact likeness. The remaining lineup and performance edit are future work; the delivered film remains unchanged.

This first proposal has swept-back dark hair with a silver front streak, a full short beard, angular drawn features, a playful half-smile, worn black leather and burgundy layers. The blue/amber stage connects to the existing drawn performance world. No user approval of this character or lineup has yet been received.

Static visual review: one person, one keyboard, face unobstructed, both hands connected naturally to the forearms, no obvious extra limb or fused hand at composition scale. Character resemblance is deliberately loose. Exact keyboard key count/grouping, musical fingering and performance animation are not validated; this is a character concept, not a production-ready instrumental performance plate. Refine instrument geometry and shot-specific hand positions before animation after character feedback.

No paid video-provider call or video edit was made for this concept. The included ChatGPT image tool was used; separate account credit charges are not measured here.
