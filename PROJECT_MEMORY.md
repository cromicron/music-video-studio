## Retrieve, reconcile, continue

1. Run `python3 tools/studio.py --refresh`. This fetches remote branches and reports local state without switching, merging or resetting. If offline, run without `--refresh` and use the documented connector fallback; do not claim a live sync.
2. Read the active [STATUS](productions/join-me-in-life/STATUS.md), [DECISIONS](productions/join-me-in-life/DECISIONS.md), [LESSONS](productions/join-me-in-life/LESSONS.md), and newest [SESSIONS](productions/join-me-in-life/SESSIONS.md) entry. Read older entries or source artifacts only as needed.
3. Consult [history coverage](docs/HISTORY_INDEX.md) and inspect relevant unmerged branch records. A newer timestamp is not authority. Current user direction governs; evidence distinguishes proposals, implementation, technical checks and acceptance. Never reset a working branch merely to match main.
4. Continue the recorded task. Verify changing facts with a small actual operation. Do not redo successful sign-ins or rejected experiments unless access has really failed or the hypothesis has changed.
5. Fold new corrections/results into their owning records during the work, especially before long jobs or a handoff. Commit coherent checkpoints; save authorized work to its remote branch and verify the exact remote SHA. Update the handoff if the task is interrupted. Follow [the session method](docs/SESSION_GUIDE.md).
